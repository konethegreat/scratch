# Trademark and brand use

The SA-JAS source code is released under the MIT licence (see [LICENSE](LICENSE)). That licence covers the code. It does not cover the project's name or identity, which stay with the author so the project cannot be misrepresented.

This note explains the boundary. It is a statement of the author's position, not legal advice.

## The marks

- **SA-JAS** and **SA Job Agent Suite**: the project names.
- The **SA-JAS wordmark** as set in the app header and the landing page.
- The **app mark**: the South African flag treatment used with the name in the header, favicon and social preview.
- The taglines and interface copy that identify the hosted instance.

Kone Tshivhinda reserves all rights in these marks. No trademark registration is claimed by this note.

## What the MIT licence lets you do

- Read, run, modify and redistribute the code, including commercially.
- Host your own instance of the software.
- Publish a fork, provided you do not present it as the official SA-JAS or imply endorsement.

## What needs written permission

- Using SA-JAS, SA Job Agent Suite, or a confusingly similar name for your own product, service, package, or domain.
- Using the wordmark or app mark in a logo, app icon, or marketing material for anything other than the unmodified project.
- Presenting a modified build as the official hosted app, or as reviewed, certified, or endorsed by the author.
- Using the marks in advertising or metadata in a way that suggests a partnership.

## What is always fine

- Referring to the project by name in articles, reviews, talks, comparisons, and course material.
- Linking to https://sajas.pages.dev or https://github.com/konethegreat/scratch.
- Stating, truthfully, that your project is a fork of SA-JAS or is built on SA-JAS, with a clear note that it is unofficial.
- Keeping the marks in an unmodified copy you run for yourself.
