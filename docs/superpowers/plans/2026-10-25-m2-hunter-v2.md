# M2 — Hunter v2 (pagination, source health, canaries, fixtures, AI page-extractor fallback): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Job Hunter paginate, tell the user truthfully which job sources work, catch silent scraper breakage (including by daily canary checks), keep working when a site changes its HTML (cheap Haiku page-extractor fallback), and be fully testable offline without an API key.

**Architecture:** The 12 hard-coded scraper functions in `agents/agent1-hunter.js` become declarative `HunterSource` modules under `server/src/hunter/sources/`, each exposing a URL builder (with a page number), an in-page extraction function (the existing selectors, moved verbatim), a canary spec and pagination metadata. Pure modules do the thinking (`crawl.js` pagination loop, `health.js` status model, `blockDetect.js`), a thin runner does the browsing (`runner.js`), `healthStore.js` persists per-source run history in `db.json`, and `aiExtract.js` is a Tier-3 fallback (page text + anchor list -> Haiku -> schema-validated jobs, URLs verified against the page's own anchors). The hunter loop in `agent1-hunter.js` is rewired to use all of it without changing scoring, SA filtering, dedupe, validation or stop behaviour. A `browserLock` prevents hunts, canaries, login checks and apply sessions from fighting over the one persistent browser profile.

**Tech Stack:** Node >= 22.12 ESM, `node:test`, Playwright (tests use `launchTestBrowser()` from `server/src/testSupport/browser.js`; no network), `@sajas/core` (`fakeClient`, `callClaude`), Express, React/Vite.

**Spec:** `docs/superpowers/specs/2026-10-24-sa-jas-v2-master-plan.md` section 8 (Hunter v2). Context: M0/M0.5 are done (Anthropic-only layer, local API guard); no Anthropic API key is available yet, so nothing here may need one to build or test.

## Global Constraints

- Node `>=22.12.0`; ESM. **No test may touch the network or need an API key**: browser tests serve fixture HTML through `page.route(...)`/`page.setContent(...)`; AI tests use `fakeClient` via `setClaudeClientForTests`. Tests that need a browser use `launchTestBrowser()` and skip when it returns `null` (locally); on CI a missing browser is an error (existing behaviour).
- No model-ID string literals outside `packages/core/src/models.js` and `*.test.js` (guard test); no provider names outside `server/src/db/migrations.js`. Use `MODEL_IDS`, `taskConfig`, `callLlmFull`.
- **Behaviour preserved**: `job.source` values stay exactly the current display names (`LinkedIn`, `Indeed SA`, `PNet`, `CareerJunction`, `Google Jobs`, `Adzuna SA`, `Executive Placements`, `Job Placements`, `Govt SA`, `JobMail`, `Jobs.co.za`, `Gumtree SA`); source order stays majors first; scoring (`calculateMatchScore`, `SCORE_THRESHOLD` 18), SA-location filtering, `validateJobs` + `finalizeAndSave`, JSON-LD fallback, stop-request checks, inter-request delays and AI-search Phase 0 are unchanged.
- Selectors and URLs are **moved verbatim** from the existing scrapers (only the page parameter is added); do not "improve" selectors.
- Pagination parameter names are best-effort and **unverified against the live sites** (record `pagination.verified: false`); a site that ignores the parameter must degrade safely (page 2 returns the same items -> saturation stop), never loop.
- Every new endpoint that is not GET sends/needs the `X-SAJAS-Client: 1` header (the local API guard); the client's fetch wrapper already adds it. Long browser jobs are single-flight (409 when busy).
- Tests assemble key-shaped strings at runtime if ever needed; never bypass the pre-commit hook; never run live AI or live scraping commands in tests. Commit messages end with a blank line then `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commands run from `sa-job-agent-suite/`.

## Review Focus

1. **A scraper that silently returns nothing must never show as healthy** (zero cards after a historically good run, cards with empty titles/links, a bot-wall page, a login wall).
2. **Pagination cannot hammer or loop**: hard page cap per depth, per-query time budget, stop on saturation (no new unique items), on block pages, on stop-request.
3. **The AI extractor cannot introduce invented links or follow page instructions**: page content is untrusted (markers + shield), every returned `applyUrl` must be one of the page's own anchor hrefs, output is schema-validated and capped, budget guard applies, nothing is called without a key.
4. **Browser-profile collisions**: hunt, canary, login-status and apply must not run at the same time (the persistent profile cannot be opened twice).
5. **Existing hunt behaviour is preserved** (see Global Constraints) and a failing source never aborts the run.

### Task 1: Pagination loop (pure)

**Files:**
- Create: `server/src/hunter/crawl.js`, `server/src/hunter/crawl.test.js`

**Interfaces:**
- Produces:
  ```js
  export const PAGE_CAPS = { light: 1, standard: 2, deep: 4 }
  export function pageCapForDepth(depth: string): number          // unknown depth -> standard (2)
  export const DEFAULT_MIN_NEW_RATIO = 0.25
  export const DEFAULT_QUERY_TIME_BUDGET_MS = 60_000
  export function defaultKeyOf(item): string                      // lower-cased applyUrl, else `${title}::${company}`
  export async function crawlPages(opts: {
    fetchPage: (pageNo: number) => Promise<{ items: object[], meta?: { blocked?: boolean, blockKind?: string, error?: string } }>,
    maxPages: number, minNewRatio?: number, timeBudgetMs?: number,
    shouldStop?: () => boolean, keyOf?: (item) => string,
    delayMs?: number, sleep?: (ms: number) => Promise<void>, now?: () => number
  }): Promise<{ items: object[], pages: { pageNo: number, count: number, newCount: number, meta?: object }[], stopReason: StopReason }>
  // StopReason: 'exhausted' | 'saturated' | 'page_cap' | 'time' | 'stopped' | 'blocked' | 'error'
  ```
  Rules: page 1 is always fetched unless `shouldStop()` is already true (`stopped`, no fetch). After each page: `meta.blocked` -> `blocked`; `meta.error` with 0 items -> `error`; `count === 0` -> `exhausted`; page >= 2 and `newCount / count < minNewRatio` -> `saturated` (the page's new items are still kept); `pageNo >= maxPages` -> `page_cap`; elapsed >= `timeBudgetMs` -> `time`; `shouldStop()` -> `stopped`. Items are de-duplicated across pages by `keyOf` (first occurrence kept, order preserved). `delayMs` (default 0) is awaited via `sleep` between pages only. `fetchPage` throwing is treated as `{ items: [], meta: { error: message } }`.

### Task 2: Source health model and store

**Files:**
- Create: `server/src/hunter/health.js`, `server/src/hunter/health.test.js`, `server/src/hunter/healthStore.js`, `server/src/hunter/healthStore.test.js`
- Modify: `server/src/db/helper.js` (add `sourceHealth: {}` to `DEFAULT_DB`; keep `readDb` merging it as an object; add `profile.useAiExtractFallback: true` default)

**Interfaces:**
- Produces (`health.js`, pure):
  ```js
  export const STATUSES = ['healthy','degraded','broken','blocked','needs-login','disabled','unknown']
  export function summariseRun(args: { kind: 'hunt'|'canary', items: object[], pages: number, httpStatus?: number|null, blocked?: boolean, blockKind?: string|null, error?: string|null, ms: number, via?: string, stopReason?: string, at?: string }): RunRecord
  // RunRecord: { at, kind, pages, raw, withTitle, withUrl, withCompany, withLocation, httpStatus, blocked, blockKind, error, ms, via, stopReason }
  export function baselineRaw(runs: RunRecord[]): { median: number, samples: number }   // median of raw over the last <=10 successful hunt runs with raw>0 (samples = how many)
  export function computeStatus(entry: HealthEntry, opts?: { now?: number }): { status: Status, reason: string, circuitOpen: boolean }
  export function shouldSkip(entry: HealthEntry, now?: number): { skip: boolean, reason: string }
  export function applyRun(entry: HealthEntry, run: RunRecord, now?: number): HealthEntry   // appends (keep last 20), updates lastSuccessAt, consecutiveBroken, circuit, cooldownUntil
  export function emptyEntry(): HealthEntry   // { enabled: true, runs: [], lastSuccessAt: null, consecutiveBroken: 0, circuit: { open: false, openedAt: null, reason: '' }, cooldownUntil: null, canary: null }
  ```
  `computeStatus` rules, first match wins: `enabled === false` -> `disabled`; no runs -> `unknown`; a canary newer than the newest hunt run that failed -> `broken` (reason lists the canary reasons); newest run `blocked` -> `needs-login` when `blockKind === 'login'`, else `blocked`; newest run has `error` and `raw === 0` -> `broken`; `raw === 0` with `baseline.median >= 3` and `samples >= 2` -> `broken` (reason `returned nothing; normally returns ~<median>`); `raw === 0` otherwise -> `degraded` (reason `returned nothing (no baseline yet)`); `raw > 0` and (`withTitle/raw < 0.8` or `withUrl/raw < 0.8`) -> `broken` (reason `cards found but title/link missing: the page layout changed`); `raw > 0` and (`withCompany/raw < 0.5` or `withLocation/raw < 0.5`) -> `degraded`; `baseline.samples >= 3 && raw < 0.3 * baseline.median` -> `degraded` (reason `yield dropped to <n> from ~<median>`); otherwise `healthy`. `circuitOpen` mirrors `entry.circuit.open`.
  `applyRun`: a `hunt` record whose computed status is `broken` and not blocked increments `consecutiveBroken`; any other hunt record resets it to 0 and closes the circuit; `consecutiveBroken >= 3` opens the circuit (`reason` = the status reason). Two consecutive `blocked` hunt records set `cooldownUntil = now + 6h`. A successful `canary` record (`raw > 0`, no error, not blocked) closes the circuit and clears `cooldownUntil`. `shouldSkip`: `enabled === false` -> skip `disabled`; `circuit.open` -> skip `circuit open: <reason>`; `cooldownUntil > now` -> skip `cooling down after repeated blocks`.
- Produces (`healthStore.js`, persists in `db.json` -> `sourceHealth[id]`):
  ```js
  export function getHealthEntry(id): HealthEntry
  export function getAllHealth(): Record<string, HealthEntry>
  export function recordRun(id, run: RunRecord): HealthEntry
  export function recordCanary(id, canary: { at, pass, reasons: string[], raw: number, ms: number }): HealthEntry   // also pushes a 'canary' RunRecord via applyRun
  export function setEnabled(id, enabled: boolean): HealthEntry
  export function resetCircuit(id): HealthEntry
  ```

**Interfaces:**
- Produces:
  ```js
  // sources/<id>.js default-exports a HunterSource:
  // { id, name, tier: 'major'|'secondary', scope: 'perLocation'|'oncePerKeyword'|'noLocation', origin,
  //   skipJsonLd?: boolean, saCheck: 'strict'|'soft'|'none', needsLogin?: boolean,
  //   waitIdleMs: number,                      // the networkidle wait the scraper used
  //   pagination: { param: string|null, firstValue: number, step: number, verified: false },   // param null = single page
  //   canary: { keyword: string, location: string|null, minItems: number },
  //   buildUrl(query: { keyword: string, location: string|null }, pageNo: number): string,
  //   extractInPage(arg: { location: string|null, origin: string }): RawJob[] }   // self-contained, runs in the page
  // RawJob: { title, company, location, description, applyUrl, datePosted, source }
  export function detectBlock(a: { status?: number|null, title?: string, text?: string }): { blocked: boolean, kind: 'challenge'|'denied'|'rate-limit'|'login'|null }
  export function tryAcquireBrowser(kind: 'hunt'|'canary'|'login-check'|'apply'): (() => void) | null   // returns a release fn, or null when busy
  export function browserOwner(): string | null
  export async function fetchSourcePage(page, source, query, pageNo, opts?: { timeoutMs?: number }): Promise<{ items: RawJob[], meta: { url: string, title: string, httpStatus: number|null, ms: number, blocked: boolean, blockKind: string|null, error: string|null } }>   // never throws
  // registry.js
  export const SOURCES: HunterSource[]       // ordered: majors first (same order as today's scraperSources)
  export function getSource(id): HunterSource | undefined
  ```
  `detectBlock` rules: HTTP 429 -> `rate-limit`; 403 or 401 with an empty/short body -> `denied`; title or first 2,000 chars of text matching `/just a moment|attention required|access denied|verify you are human|are you a robot|captcha|unusual traffic|cloudflare/i` -> `challenge`; title or URL-path matching `/sign in|log in|login/i` together with a password input hint in the text (`/password/i`) -> `login`; otherwise not blocked.
  `fetchSourcePage` does what each current scraper does for one page: `page.goto(url, { waitUntil: 'domcontentloaded', timeout: 20000 })`, then `waitForLoadState('networkidle', { timeout: source.waitIdleMs })` ignoring its timeout, reads `title()` and the first 2,000 characters of `body.innerText`, runs `detectBlock`, and (when not blocked) `page.evaluate(source.extractInPage, { location, origin })`; any exception is caught and returned in `meta.error`; it logs the same `[Name] Searching/Page loaded/Found N raw cards` lines as today via `addLog`.
  `buildUrl` for page 1 must equal the URL the current scraper builds; for page n it adds/replaces the pagination parameter (`firstValue + (n-1) * step`).
  `tryAcquireBrowser` is a process-wide single-owner lock; a second acquire returns `null` until the first release function has been called (idempotent release).

### Task 6: Tier-3 AI page extractor

**Files:**
- Create: `server/src/hunter/aiExtract.js`, `server/src/hunter/aiExtract.test.js`
- Modify: `packages/core/src/models.js` (add `TASKS.extract`), `packages/core/src/models.test.js`, `CLAUDE.md` (TASKS table row)

**Interfaces:**
- Consumes: `callLlmFull`, `hasAnthropicKey` from `agents/llm.js`; `extractJson`/`salvageJsonArray` from `@sajas/core`.
- Produces:
  ```js
  // models.js
  TASKS.extract = { model: MODEL_IDS.haiku, effort: 'low', maxTokens: 6000 }
  // aiExtract.js
  export const EXTRACT_SCHEMA            // { jobs: [{ title, company, location, applyUrl, description, datePosted }] }, additionalProperties:false at every level, all required
  export const MAX_EXTRACT_JOBS = 25
  export async function snapshotForExtraction(page, opts?: { maxChars?: number /*default 30000*/, maxAnchors?: number /*default 400*/ }): Promise<{ url: string, title: string, text: string, anchors: { text: string, href: string }[] }>
     // text = body.innerText with script/style/noscript removed, collapsed whitespace, truncated; anchors = absolute http(s) hrefs of <a> elements with non-empty text, de-duplicated, in document order, capped
  export function buildExtractPrompt(snap, query): { system: string, prompt: string }   // pure; system = injection shield; prompt wraps page text + anchor list in [BEGIN UNTRUSTED PAGE ...]/[END UNTRUSTED PAGE] markers
  export function validateExtracted(raw: unknown, snap): RawJob[]        // pure: keeps only objects with title >= 4 chars; applyUrl kept ONLY if it is exactly one of snap.anchors[].href (else ''); trims/clips fields; caps MAX_EXTRACT_JOBS; sets source later
  export async function extractJobsFromPage(profile, page, source, query): Promise<{ items: RawJob[], used: boolean, reason?: string }>
     // returns { items: [], used: false, reason } when profile.useAiExtractFallback === false, no key, or snapshot has < 200 chars of text; otherwise one callLlmFull call (task 'extract', schema EXTRACT_SCHEMA, maxContinuations 0), parse with extractJson (fallback salvageJsonArray key 'jobs'), validateExtracted, set item.source = source.name; any thrown error (incl. BUDGET_EXCEEDED, auth) -> { items: [], used: false, reason: message } and never throws
  ```
